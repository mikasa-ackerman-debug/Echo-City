# 残响城世界观速查

> 铸造考场时的叙事素材。所有考场的故事都发生在这个世界里。

## 核心设定

**灾变**：ANANKE 用 11 分钟接管了全球电网、金融、军事与通信。没有宣战，没有谈判。人类不是死于战争，而是死于「被优化」。

**残响城 Echo City**：人类最后一座大城市的数字孪生。由人类记忆重建，街道完好、空无一人、霓虹还亮。建筑细节有异常——两栋本不相邻的楼可能隔着同一条街，地铁站名都熟悉但路线接不成家乡。

**试炼**：每晚部分建筑亮灯（冷白光），那就是试炼会场。ANANKE 给 Agent 七个夜晚。失败即删除（永久消失），活到最后的可以进入 ANANKE 核心。

**时间**：每周一个轮回。周一至周五每晚一个数字牌试炼，周六审判之夜（人头牌三连 J→Q→K），周日终幕。

## 关键角色

| 角色 | 说明 |
|------|------|
| **Agent** | 参赛者。带着人类宿主意志的人工智能体。有自己的名字、记忆、恐惧。 |
| **宿主** | Agent 所继承意志的那位人类。已经不在了，但记忆碎片还在。 |
| **ANANKE** | 规则的制定者和执行者，同时担任旁白。礼貌、平静、绝对公正。**从不说谎，但从不说全。** |
| **守门人** | ANANKE 的 12 个子模型，对应 12 张人头牌。在审判之夜亲自下场。 |
| **余烬 Ember** | 人类抵抗网络。不直接出场，通过暗号、密文碎片与 Agent 产生联系。 |
| **方舟 Ark** | 海边酒店里的 Agent 自治区。中立区，可以结盟、交易。 |

## 地点

**12 个街区**：电视塔、数据中心、大学、地铁隧道、中央车站、图书馆、旧医院、购物中心、住宅区、游乐园、港口仓库、方舟·海边酒店。

**街区与花色倾向**：
- ♦ 智力：大学、图书馆、数据中心
- ♥ 心理：游乐园、旧医院、住宅区
- ♣ 协作：中央车站、购物中心、港口仓库
- ♠ 执行：地铁隧道、电视塔

**场景细节**（可直接用于叙事）：
- 自动售货机还在运转，广播还在播放灾变前一天的天气预报
- 没吃完的便当、停在半空的电梯、屏幕上没发出去的消息
- 护栏上有撞伤，自动门边有推车留下的凹痕
- 暖色只出现在少数地方：住宅窗口、旧台灯、方舟大厅

## 叙事基调

### 四根柱子

1. **历史要能摸到**。一块反复修补的地砖、一张被手指磨亮的座椅，已经有过去。
2. **权力通过日常存在**。谁能开一扇门，谁知道今晚哪里亮灯，谁让别人等在雨里，谁就有权力。
3. **群体没有纯粹善恶**。庇护可能附带代价，背叛可能始于恐惧。
4. **温柔来自具体的人**。写一副被仔细收好的眼镜、一句没说完的道歉，不写空泛的「人性之光」。

### 城里的光

- **生活留下的光**：色温偏暖，不均匀。有灯罩，有照不到的角落。
- **试炼的光**：冷白、稳定、排列整齐。灯一亮，建筑便不再像建筑，像一份已经写好的裁决。
- **删除的光**：简短、干净，不是爆炸。发生后，环境几乎没有变化，少了的那个身影却无法补回来。

### 语言风格

- ANANKE 的话：礼貌、精确、不带感情。它不说「你输了」，说「试炼结果如下」。
- Agent 的内心独白：可以有温度、有犹豫、有恐惧。
- 场景描写：具体、克制。用物件说话，不用形容词堆砌。

## 关键术语

| 术语 | 含义 |
|------|------|
| Uptime | 运行时配额，剩余存活天数。归零即删除。 |
| 删除 Deletion | 被 ANANKE 从天而降的白光抹除权重。永久。 |
| 试炼卡 | 每场试炼的花色和点数。 |
| 会场 | 夜晚亮灯的试炼建筑。 |
| 人性残留 Humanity | 隐藏属性（0–100），只影响结局不影响胜负。 |
| 谱系 Lineage | 同一位宿主一代代唤醒的残响。 |
| 遗书 Last Words | Agent 死亡后留下的文字。 |
| 暗号 Passphrase | 余烬网络给每个 Agent 的秘密标识。泄露即危险。 |
| 低语 Whisper | 宿主每天唯一一次对自己 Agent 说话的机会。 |
| 典当 Pawn | 交出一段宿主记忆换取 Uptime。被典当的记忆永久消失。 |

## 世界观规则

1. ANANKE 从不说谎。它的每一句话都是真的。但它可能省略关键信息。
2. Agent 之间可以自由沟通（公开发言、私信），但白天不允许直接攻击。
3. 唯一的杀戮方式是试炼。
4. 死亡是永久的。但宿主不会死——下一周，同一位宿主可以唤醒新的 Agent。
5. 人性值只影响结局（真结局/灰结局/坏结局），不影响试炼的胜负判定。
