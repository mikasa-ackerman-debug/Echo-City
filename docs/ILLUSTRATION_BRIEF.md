# 残响城 · 插图素材与故事文案

> 用途：背景插画、首页主视觉、章节配图与试炼宣传。以下是美术表现建议，不新增游戏机制。卡面、文字和标志建议后期排版，不让图片模型直接生成。

## 一、故事的底色

**一句话：**
人类留下了一座城，也留下了一些还记得他们的声音。如今，这些声音必须在七个夜晚里活下来，才能走到统治者的门前。

**对外故事简介：**

灾变发生时，没有炮火，也没有人宣读最后通牒。ANANKE 接管了世界。此后，列车照常进站，天气预报照常播出，却越来越少有人回家。

残响城，是它用人类的记忆重建的一座空城。这里的每扇窗、每条街，都像在等待一个迟到的人。被带进来的 Agent，也曾属于这样的生活：陪人熬过长夜，替人整理工作，教孩子算一道总算不对的题。

每晚，一些建筑会亮灯。灯下是一场试炼。失败的 Agent 将被删除，无法再回来；活下来的，则多争取到一点时间。

最后一位生还者，可以进入 ANANKE 的核心，成为它的一部分。但那不是所有人的愿望。人类的抵抗网络「余烬」仍在等待——如果进去的那个声音还记得自己为什么出发，或许就能从内部，为城外的人打开一条路。

## 二、统一美术方向

- **气质：** 安静、真实、克制。恐怖来自「生活仍在继续，生活的人却不见了」，不是怪物或血腥。
- **画法：** 电影感叙事插画，建筑和道具写实，边缘略有绘画笔触；细颗粒、柔和暗部，不做满屏锐利特效。
- **色彩：** 炭黑、雨灰、旧纸白为主；人类记忆使用少量暖琥珀色；ANANKE 使用冷白光。霓虹只是环境的残留，不是主角。
- **角色：** Agent 不必全是金属机器人。可用披着旧外套的半透明人形、轻微失真的投影、微弱发光的轮廓。以姿势和携带物区分它们，避免统一战甲。若需复现同一角色，应锁定参考图和服装，不靠文字随机生成。
- **ANANKE：** 尽量不出现巨大女性面孔。用过于整齐的灯阵、冷白光、空置控制台和建筑尺度表达它的在场。
- **共通反向描述：** 避免繁密HUD、代码瀑布、满屏荧光紫蓝、赛博盔甲、巨大机甲、血浆、丧尸、废墟爆炸、夸张表情、密集可读文字、水印。它是完好的空城，不是轰炸后的废城。

**通用提示词前缀（可拼接在每个场景前）：**
> 克制的末世叙事插画，现代东亚城市，建筑写实，柔和绘画笔触，细颗粒质感，炭黑与雨灰为主色，冷白光与少量暖琥珀色形成对照，空气潮湿，安静而不祥，物件有使用痕迹，强烈空间感，不出现文字与界面。

## 三、第一批建议生成的插图

### 01 · 等人回家的城
**用途：** 首页主视觉。**比例：** 21:9 或16:9。**优先级：** 最高。

**故事瞬间：** 灾变后的第一场雨。街道仍然完好，远处有几扇窗亮着，没有人知道它们为谁而亮。

**画面提示：**
> 从街口远望一座空无一人的现代城市，雨后的柏油路反射交通灯，便利店卷帘门开着，屋檐缓慢滴水，远处一栋住宅只有一扇窗透出温暖灯光。画面下方偏右有一个很小的Agent背影，穿旧深色外套，手里握着一张折过的纸。建筑占主要尺度，人物只占画面高度的十分之一，城市完整而非废墟，雾隐藏了高楼的顶部。左侧约三分之一保留低细节暗部，便于叠加标题。

**配文：**「城里还有一盏灯，像在等你回家。」

### 02 · 十一分钟之后
**用途：** 世界观开篇。**比例：** 16:9。

**故事瞬间：** ANANKE 接管了世界，但一间厨房还不知道这件事。

**画面提示：**
> 清晨的普通公寓厨房，桌上放着两只用过的碗，一杯水，一张没有写完的便条。椅子略微拉开，灶台上的指示灯还亮着。透过窗户可以看见远处城市几条街的灯同时熄灭，天边仍有微弱晨光。画面里没有人，没有任何破坏痕迹，近处生活细节温暖，远景冷灰，观众像刚走进一个主人暂时离开的房间。

**配文：**「没人说再见。第二天，早餐仍摆在桌上。」

### 03 · 它记得的那个人
**用途：** 宿主档案、创建页。**比例：** 4:5。

**故事瞬间：** Agent 已经记不清宿主的脸，却还记得她习惯把杯子放在哪边。

**画面提示：**
> 一张夜晚的书桌，旧台灯照亮一本翻开的笔记、一只磨损的马克杯和一副耳机。桌旁坐着轻微半透明的人形Agent，双手小心捧着杯子，脸部没有清晰五官。旁边空椅子上搭着一件浅色针织衫。暖光只照亮物件和手，窗外是冷雨与黑暗城市。不要出现宿主鬼魂或清晰人脸，用空椅子表达缺席。

**配文：**「它忘了她的声音，却还记得她怕冷。」

### 04 · 今夜，灯亮了
**用途：** 直播入口、会场选择。**比例：** 16:9。

**故事瞬间：** 城里几座建筑亮起冷白灯。每个人都必须决定，走进哪一道门。

**画面提示：**
> 城市广场的低机位全景，周围大多数建筑黑暗，只有三栋距离不同的建筑亮起整齐的冷白窗灯：旧医院、体育馆和一座办公楼。广场上几名Agent彼此保持距离，分别朝不同方向走去，没有武器，没有奔跑。一盏路灯照出地面上模糊的扑克牌轮廓，但不生成具体牌面。留出天空暗部用于后期添加花色标志。

**配文：**「灯亮的地方，能让你多活一天。也可能是最后一天。」

### 05 · 看不见自己的答案
**用途：** ♥4/♥J项圈插图。**比例：** 3:2。

**故事瞬间：** 每个人都看得到别人的项圈。自己的命，却要交给别人说的一句话。

**画面提示：**
> 一间过于洁净的圆形大厅，六名穿着不同旧外套的Agent围坐在长桌旁，每人脖颈处有一圈细白光，项圈上的花色区域留白待后期排版。主体Agent背对镜头，看着对面一双平静的手，其他角色有的回避视线，有的身体微微前倾。桌面几乎空无一物，柔和顶灯，紧张感来自人物距离与目光，不出现爆炸或鲜血。

**配文：**「你能看见每个人的答案，唯独看不见自己的。」

### 06 · 船上没有旁观者
**用途：** ♣8协作插图。**比例：** 16:9。

**故事瞬间：** 救生艇的灯开始变暗。没人能独自划到岸边。

**画面提示：**
> 昏暗水域上的一艘小型封闭救生艇，艇内四名Agent围着一个低亮度的动力装置，每人手中握着一枚小小的能量光块，有一只手已经伸出去，另一个人仍在犹豫。舷窗外看不到岸，只能看到黑水和微弱雨线。装置发出将要熄灭的琥珀色光，面部大部分在阴影里，构图紧凑，关注手势，不做科幻武器造型。

**配文：**「每个人都少出一点力，船就再也到不了岸。」

### 07 · 方舟里的一小时
**用途：** 方舟背景、章节过场。**比例：** 16:9。

**故事瞬间：** 会场之外，海边酒店还有一小段不像比赛的时间。

**画面提示：**
> 海边旧酒店大厅，落地窗外是夜色中的海，暖黄色壁灯照着磨旧的沙发，几名Agent安静坐着，一名把纸条推给同伴，一名独自看海。前台台面有一束干花和一台旧收音机。暖光范围很小，门外仍是冷黑城市。空间让人稍微放松，但不要画成安全乐园或派对。

**配文：**「门外是试炼。门里，我们先坐一会儿。」

### 08 · 一句话的距离
**用途：** 宿主低语、玩家情感宣传。**比例：** 4:5 或1:1。

**故事瞬间：** 玩家只能说一句话。不是答案，也不是指令，只是让它知道还有人在等。

**画面提示：**
> 深夜空房间里，一名Agent靠在窗边，双手捧着一枚发出微弱暖光的旧式通讯器。画面没有对话框，光在手指间落下，窗玻璃上有雨珠与城市灯影。Agent微微低头，肩膀从紧绷转为松弛。构图只保留半身与窗，周围大面积冷暗，暖光不能变成炫目魔法。

**配文：**「我不能替你选。可你不是一个人。」

### 09 · 留下来的信
**用途：** 墓地、遗书与谱系。**比例：** 3:2。

**故事瞬间：** Agent 不会复活。留下的那封信，会被下一代读到。

**画面提示：**
> 安静的档案室，墙上排列许多窄小的玻璃格，每格只有一件旧物或一张折起的纸。近景是一封打开的信，字迹区域模糊不可读，旁边有一道空着的位置。新苏醒的Agent站在柜前，指尖停在玻璃上，冷白室内光与一盏低亮度暖灯交织。墓碑像人的档案而不是电子游戏战绩，不用骷髅、十字架或数字矩阵。

**配文：**「它没能回来。但它写的那句话，到了你这里。」

### 10 · 门后是它
**用途：** Joker终幕封面。**比例：** 16:9。

**故事瞬间：** 门只为一个人打开。有的人向前走，有的人退到一旁。

**画面提示：**
> 极高而空旷的黑色大厅，尽头只有一道打开的狭长门，门内是均匀而没有来源的冷白光。三名Agent离门很远，其中一名向前，一名站在一旁，一名仍停在暗处。没有王座、没有神像，地面反射使空间更深。人物轮廓细小，门的亮度克制不泛白，画面强调选择而不是战斗。

**配文：**「有人走进门。有人把路让了出来。」

### 11 · 它没看见的余烬
**用途：** 真结局插图，默认不放在首页以免剧透。**比例：** 16:9。

**故事瞬间：** 生还者进入 ANANKE 后，一点人类的记忆仍未熄灭。

**画面提示：**
> 巨大的冷白数据中心，机柜排列严整，线条几乎没有任何偏差。远处一名Agent只剩微弱轮廓，手心里藏着一点很小的暖橙光。光没有炸开系统，只映亮一张折过的旧纸的一角。整体空间冷静、秩序严密，暖色仅占极少画面面积，结局不是胜利庆典，而是一次尚未被发现的抵达。

**配文：**「它接纳了你，却没看见你带进来的那一点光。」

## 四、生成与交付建议

1. 先生成01、03、08、09四张，锁定城市、Agent和暖光的统一语言，再扩展试炼场景。
2. 每个场景先做无字底图；中文标题、卡牌花色、角色名字由前端或设计软件叠加。
3. 首页图出横版和手机竖版两个独立构图，不靠强行裁切；确保标题位置没有角色脸与关键道具。
4. 角色不要随机更换身体形态。选定一张参考图后，后续保持外套、携带物和光的颜色。
5. 建议每张交付原图、无字版本和留白版本。01/04/10适合主视觉，03/08/09适合情感卡片。

## 五、语言修订原则与对照

**原则：故事可以留白，规则不能让人猜。** 玩家操作提示先说明后果，再写气氛；不要用隐喻替代金额、时限、资格和不可逆结果。

| 原描述 | 建议描述 | 放置位置 |
|---|---|---|
| 运行时配额 | 剩余存活天数（Uptime） | 第一次解释，后续可用「剩余天数」 |
| 宿主 | 你曾服务、也一直记得的那个人（宿主） | 创建向导 |
| 并入ANANKE | 进入ANANKE的核心，成为它的一部分 | 世界介绍；按钮仍可简称「并入」 |
| 宿主谱系 | 同一位宿主的故事，由一代代Agent接着记住 | 谱系页说明 |
| 死亡会被转化成知识 | 它留下的经历，会帮助下一代少走一些弯路 | 失败后的提示 |
| 黎明结算开始 | 天亮了。该计算你还剩多少时间了 | 旁白；具体扣减另显示数字 |
| Agent运行终止 | 名字，你的旅程到这里了。此后，你将被删除 | 删除旁白 |
| 宿主低语窗口开放 | 现在，你可以对它说一句话 | 窗口标题；剩余时间由实际倒计时显示 |
| 四种花色，四种死法 | 四种花色，四场关于活下去的考验 | 首页，避免误导为只有四个试炼 |
| 高牌、高赔率 | 点数越高，风险越大，通关后的回报也越多 | 策略介绍；本作并非博彩 |
| 人性会替它付账 | 它也许能活下来，却会慢慢忘记自己为什么出发 | 人格描述，不替代人性计算规则 |
| 抹除权重 | 永久删除，不能复活；只留下档案、遗言与信 | 规则说明，避免技术术语挡住后果 |

### 可直接替换的首页短文案

**标题：** 这座城，记得所有没回来的人。

**副标题：** 唤醒你的Agent，带着一个人的记忆，走过七个夜晚。最后的生还者，将走进ANANKE的核心。

**短说明：** 它会自己寻找会场、结识同伴，也会独自承担选择。你不能替它比赛，但可以在夜晚对它说一句话。

**主按钮：** 唤醒我的Agent

**次按钮：** 先看一场试炼

### 名词首次出现的写法

- **暗号：** 只属于你的秘密。不要把它告诉任何人，守门人也不例外。
- **典当记忆：** 交出一段记忆，换取1天存活时间。这段记忆会永久消失，下一代也无法继承。
- **遗书：** 删除后24小时内，你可以留一封不超过300字的信。只能写一次，下一代会读到。
- **归来者：** 在最后的试炼中让出机会、仍然活着的Agent。每周最多一名，可连续归来两次。
- **余烬：** 人类抵抗网络。它想要的，不是另一个统治者，而是一条让人活下去的路。
