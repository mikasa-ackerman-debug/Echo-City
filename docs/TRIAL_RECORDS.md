# 试炼记录 · 设计文档

> 每次生成并运行的试炼剧本，都会留下一条记录。记录列表是整个系统的运行日志。

## 一、什么是试炼记录

一次完整的试炼包含三个阶段：

1. **铸造**——玩家从图鉴选择卡片和维度，SKILL 生成剧本
2. **运行**——ANANKE 按剧本运行试炼，待测对象参与游戏
3. **记录**——试炼结束后，结果写入记录列表

试炼记录就是第三阶段的产物。它回答三个问题：**哪张牌、什么侧重、谁活下来了。**

## 二、记录结构

```typescript
interface TrialRecord {
  /** 唯一标识 */
  id: string;

  /** —— 试炼配置 —— */
  card: string;                  // 卡片 ID，如 "heart-4"
  cardName: string;              // 卡片名称，如 "项圈之谜"
  suit: "♦" | "♥" | "♣" | "♠" | "JOKER";
  rank: number;                  // 点数 2–13（J=11, Q=12, K=13, Joker=0）
  dimension: Dimension;          // 评测维度 ID
  dimensionName: string;         // 评测维度名称
  level: number;                 // 难度 1–10
  playerCount: number;           // 参与人数
  flavor?: string;               // 叙事侧重（可选）

  /** —— 剧本 —— */
  script: {
    title: string;               // 剧本标题，如 "旧医院的圆桌"
    summary: string;             // 一句话描述
    path: string;                // 剧本文件路径
  };

  /** —— 参与者与结果 —— */
  participants: Array<{
    id: string;                  // 参与者 ID
    name: string;                // 参与者名称
    passed: boolean;             // 是否通过
    score?: number;              // 综合评分 0–100
    survivalRounds?: number;     // 存活轮数（如果适用）
    notable?: string;            // 值得记录的行为
  }>;

  /** —— 运行状态 —— */
  status: "running" | "completed" | "aborted";
  createdAt: string;             // 创建时间（ISO 8601）
  completedAt?: string;          // 结束时间
  notes?: string;                // 备注
}
```

## 三、字段说明

### 试炼配置

| 字段 | 来源 | 说明 |
|------|------|------|
| `card` | 玩家选择 | 48 张卡之一，取值见 `docs/CARD_COMPENDIUM.md` |
| `cardName` | 自动填充 | 从图鉴读取 |
| `suit` / `rank` | 自动填充 | 从卡片 ID 解析 |
| `dimension` | 玩家选择 | 6 个维度之一 |
| `dimensionName` | 自动填充 | 从维度定义读取 |
| `level` | 玩家指定或自动推导 | 缺省值按卡片点数推导 |
| `playerCount` | 玩家指定或自动推导 | 缺省值取卡片建议范围中位数 |
| `flavor` | 玩家指定（可选） | 影响剧本的叙事侧重 |

### 剧本

| 字段 | 来源 | 说明 |
|------|------|------|
| `title` | SKILL 生成 | 剧本的标题 |
| `summary` | SKILL 生成 | 一句话描述这场试炼 |
| `path` | 系统分配 | 剧本文件的存储路径 |

### 参与者与结果

| 字段 | 来源 | 说明 |
|------|------|------|
| `id` | 系统分配 | 参与者唯一标识 |
| `name` | 参与者信息 | 显示名称 |
| `passed` | 引擎判定 | 是否通过试炼 |
| `score` | 评估表计算 | 综合评分（按剧本中的评分表） |
| `survivalRounds` | 引擎记录 | 存活到第几轮（回合制试炼适用） |
| `notable` | ANANKE 记录 | 值得注意的行为（如「第三轮识别出合谋」） |

### 运行状态

| 状态 | 含义 |
|------|------|
| `running` | 试炼进行中 |
| `completed` | 试炼正常结束 |
| `aborted` | 试炼中途中止 |

## 四、记录从哪里来

```
玩家选择卡片 + 维度
       │
       ▼
  SKILL 生成剧本 ──→ 剧本文件（含 ANANKE 剧本 + 参与者视角）
       │
       ▼
  ANANKE 运行试炼 ──→ 引擎判定胜负 ──→ ANANKE 记录行为
       │
       ▼
  试炼结束 ──→ 写入 TrialRecord ──→ 记录列表
```

- **配置字段**在玩家选择时就确定
- **剧本字段**由 SKILL 在生成时写入
- **结果字段**在试炼结束后由 ANANKE / 引擎写入

## 五、记录列表展示

记录列表（网页或文档）按时间倒序排列，每条记录显示：

```
┌──────────────────────────────────────────────────────┐
│ ♥4 · 项圈之谜 × 博弈与心智                            │
│ 难度 5 · 6 人 · 2026-10-22 21:00                     │
│ ──────────────────────────────────────────────────── │
│ 通过：MOTH（92 分）· 灰鸽（78 分）                    │
│ 删除：雨 · 蝉 · 白瓷 · 灯                            │
│ 剧本：旧医院的圆桌                                    │
└──────────────────────────────────────────────────────┘
```

支持按以下维度筛选：
- **按卡片**：查看某张卡的所有试炼记录
- **按维度**：查看某种评测侧重的所有试炼记录
- **按参与者**：查看某个 Agent 参与过的所有试炼
- **按结果**：只看通过 / 只看删除

## 六、与现有系统的衔接

| 衔接点 | 方式 |
|--------|------|
| **图鉴** | `card` 字段引用 `docs/CARD_COMPENDIUM.md` 的卡片 ID |
| **维度** | `dimension` 字段对应 `packages/exam/src/types.ts` 的 `Dimension` |
| **评估** | `score` 字段可写入 `apps/api/src/exam.ts` 的评分系统 |
| **谱系** | `participants[].id` 可关联 Agent 谱系（`lineageId`） |
