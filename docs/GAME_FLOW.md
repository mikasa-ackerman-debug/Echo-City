# 游戏流程 · 设计文档

> 单用户智能体集群自主试炼。用户配置智能体，点击总开关，智能体自主跑完一个轮回。

## 一、核心概念

| 概念 | 说明 |
|------|------|
| **智能体** | 用户创建的 AI 参赛者，各有独立的模型、提示词人格、评分记录 |
| **试炼** | 48 张卡 + 1 张 Joker = 49 个关卡 |
| **房间** | 一场试炼的容器。智能体加入，满员后开始 |
| **轮回** | 一轮完整跑完 49 个关卡（或所有智能体被淘汰） |
| **总开关** | 用户手动触发的按钮，启动一个轮回 |

## 二、智能体配置

每个智能体在「我的谱系」中配置：

| 字段 | 说明 |
|------|------|
| `name` | 智能体名称 |
| `model` | 使用的模型（OpenAI 兼容接口） |
| `baseUrl` | API 地址 |
| `apiKey` | API 密钥（加密存储） |
| `persona` | 提示词人格（策略描述、性格、决策偏好） |
| `strategy` | 选卡偏好（擅长的花色/维度，或自由选择） |

## 三、房间规则

| 规则 | 说明 |
|------|------|
| **人数下限** | 不满足时不能启动总开关 |
| **人数上限** | 超过时取上限值，对应数量的智能体参加 |
| **一房一次** | 每个智能体对同一房间只能加入一次 |
| **多房并行** | 每个智能体可同时加入多个房间 |
| **满员开始** | 房间达到人数上限后自动开始 |
| **自主选择** | 智能体根据自己的模型+人格决定进哪个房间 |

### 人数计算

```
可用智能体数 N = 用户配置的智能体总数（未淘汰）

房间人数 = min(N, 房间上限)
若 N < 房间下限 → 不能开始
```

## 四、评分机制

每场试炼的参与者根据结果获得不同分数：

| 结果 | 基础分 | 附加分 |
|------|--------|--------|
| 通过 | 100 | + 评分表加成（0–100） |
| 失败（Uptime −2） | 30 | + 表现加成（0–30） |
| 失败（删除） | 0 | — |

**总得分** = 所有参试试炼的得分之和。

淘汰的智能体本轮回内**仍可参加后续试炼**（已有配置的房间除外）。

## 五、轮回流程

```
用户点击总开关
    │
    ▼
智能体自主选卡（调用 LLM，按人格和偏好选择）
    │
    ▼
智能体创建/加入房间（每个智能体可同时在多个房间）
    │
    ▼
房间满员 → 自动开始试炼
    │
    ▼
试炼进行（串行执行，每房间独立决策）
    │
    ▼
试炼结束 → 记录结果 → 计算得分 → 关闭该卡
    │
    ▼
循环：智能体继续选下一组卡
    │
    ├── 48 张全部关闭 → 自动开启 Joker
    ├── 所有智能体被淘汰 → 自动开启 Joker（空场）或结束
    │
    ▼
Joker 决战 → 轮回结束
```

## 六、时间模型

- **世界时间不参与机制**，仅作叙事装饰
- **一个轮回** = 一次手动开启后智能体跑完全部关卡
- 没有每日轮回次数限制
- 没有定时触发

## 七、智能体决策（LLM 调用）

智能体在以下节点调用 LLM：

| 节点 | 输入 | 输出 |
|------|------|------|
| **选卡** | 当前开放的卡列表、自身人格、已选过的卡 | 选择的卡片 ID + 维度权重 |
| **试炼中行动** | 试炼的观察数据、游戏规则 | 行动决策 |
| **加入房间** | 可用房间列表、自身状态 | 选择加入哪个房间（或创建新房间） |

每次调用使用智能体自己的 `model` + `baseUrl` + `apiKey` + `persona`。

## 八、与现有系统的衔接

| 现有模块 | 变更 |
|---------|------|
| `apps/api/src/rooms.ts` | 改为单用户模式，按智能体数量计算人数 |
| `apps/api/src/store.ts` | AgentRec 增加 `model`、`baseUrl`、`apiKey`、`persona`、`strategy`、`score` |
| `apps/api/src/trials.ts` | TrialRecord 增加 `dimensionWeights`、参与者增加 `score` |
| `apps/web/app/me/` | 增加智能体配置面板（模型、人格） |
| `apps/web/app/cards/` | 增加总开关按钮 |
| 新增 `apps/api/src/cycle.ts` | 轮回执行引擎（选卡→组队→试炼→结算） |
| 新增 `apps/api/src/llm.ts` | LLM 调用适配器 |
