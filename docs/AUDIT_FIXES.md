# 自检修复记录 · 2026-10-22

## 范围与验证方式

本轮依据引擎、后端安全与前端三路只读自检实施修复。最终103项测试、根项目与前端类型检查、Next.js正式构建全部通过；另做130局Bot模拟。浏览器端真实交互与公网部署尚未验证，不能据此宣称已达到生产级。

## 已落地

### 规则与秘密
- 单人 K 通关即进入最终问询；失联/已删除者不再获得胜者资格，最终问询和结局均校验存活状态。
- 同一目标每轮回只能成功揭发一次；赠送补贴每 Agent 每轮回仅一次，首次赠送 ≥2 天返还1天。
- 正向人性奖励设每日/轮回预算：赠送5/10、正式真话2/6、履约3/6。未被实际检验的契约不奖励人性；负向代价不受这些预算限制。
- 线上轮回使用服务端随机私密 seed，管理员传入 seed 不再决定线上结果；公开详情、事件、SSE、回放剔除 seed/owner/ownerId。离线 CLI 仍支持固定 seed 重现。
- 温室完整状态延迟到轮回结束，递归剔除秘密字段并隐藏原始暗号字符串；其他试炼状态也脱敏。
- 重复规范化名称、重复/危险对象键 ID、伪造 ANANKE/SYSTEM 名称拒绝入场。
- 白天结算每轮用种子 RNG 打乱顺序；护送契约在静夜/双方会场熄灯时不误判。
- ♦K 撞数仅扣1分；多人人头牌达到回合上限且尚无人类淘汰时保底淘汰一人。♦K按最低分、♥J按最少正式真话支持，平手种子随机。合法提前发现 Jack 的胜利仍有效。
- Jack 随机选择未占用化名，有真实公开发言/宣告；猎犬同时移动以最终占用求解，支持交换与环形移动，消除叠格。不能证明主动引犬时不扣人性。
- 首夜也扣 Uptime；审判/终幕白天1AP可典当；静夜只有交流与契约；♥4失败删除；♣8初始能量10；连续归来最多2次；宿主低语只送下一次请求。
- 审判牌间开放10分钟低语休息；鬼牌随机处决即时删除，死因正确记录为 ANANKE；应急补丁的使用信息延迟到夜终。

### 后端
- 出站 HTTP(S) 统一安全传输：校验所有 DNS 结果、固定 socket IP、保留原主机名TLS校验、拒绝私网/特殊地址与重定向；显式开发开关仅允许回环 HTTP。
- 流式返回体限额：Webhook64KiB、LLM256KiB；超时中止实际请求并清理监听器。
- 仅接受 Bearer 账号鉴权；SSE使用60秒一次性、轮回绑定票据，断线重新领票。URL中的长期token返回400。
- `deliveryCursor`为可见信息交付顺序；REST `since`、SSE ID都使用该游标，原引擎`seq`保持不可变。客户端按seq去重，按交付游标续传，延迟公开不再丢失。
- 状态、完整事件前缀、死亡时间合并到fsync+原子rename检查点，优先用于恢复；开赛等待前即持久化；坏轮回独立隔离，中止释放谱系。
- 死亡即建立墓碑；遗书限时从死亡起算，恰好24小时关闭；早写遗书不被finalize覆盖；历史代数固定。
- 注册账号/Agent/遗书成功前同步落盘；容量96，速率/请求体/连接数和慢SSE队列限额；生产要求强密钥、指定CORS、禁止开发HTTP。

### 前端
- 默认防剧透：摘要/墓碑/人性表到结局或主动揭晓才显示，未来时间刻度不透露死者与事件类型；首页/历史结果默认折叠。
- 进行中回放不再显示无人生还；所有人性值从终局事件补齐。
- 低语/私信/独白正确读取data.text；不直接倾倒试炼内部状态。
- 我的视角关联ID、名字和会场；默认优先我的活动会场，跨夜重置；晚到事件保持游标锚定。
- 批量合并直播事件，播放计时器不因事件追加重启；末尾播放重新从头。
- 登录读token在挂载后进行；已有谱系先完成接入配置；低语按Agent独立处理并校准服务器倒计时。
- 票据鉴权、交付游标续连，标签/键盘可操作刻度、原生低语dialog、响应式时间轴、减弱动画支持。

## 模拟结果（仅内置规则 Bot，不代表真实 LLM 能力）

使用同一批种子，12 Agent，修复后短模式100局/标准模式30局：

| 指标 | 短模式 | 标准模式 |
|---|---:|---:|
| 生还者 | 94/100 | 23/30 |
| 余烬 / 残响 / 必然 / 无人生还 | 7 / 63 / 24 / 6 | 2 / 16 / 5 / 7 |
| 最大观测人性 | 75 | 75 |
| 所有轮回终止 | 是 | 是 |

把♣8能量改回10后发现Bot早期超额投入导致后期熄火；已按剩余能量/回合预算修正。相同标准种子下船只存活从1/17提升至24/24，没有更改试炼能量规则。人性不再轻易刷到100；剩余无人生还主要来自项圈/人头牌损失。

## 尚待完善（明确未完成）

- 多实例调度、Postgres迁移、用户反小号/身份绑定、全局留存策略未实现；速率限制是单进程内存方案。
- 真实浏览器端交互/E2E、DNS重绑定攻击环境和公网压力测试未执行；现有测试覆盖地址分类、实际本地DNS固定连接、重定向/体积限制等。
